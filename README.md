# منصة التدريب التعاوني وشؤون الخريجين

منصة ويب لإدارة التدريب التعاوني في الكلية التقنية ببيشة: المتدربون وجهات التدريب، والزيارات الميدانية، والتقارير الأسبوعية، وتقييم جهات التدريب، وشؤون الخريجين.

**التقنية:** PHP 8 + MySQL، وتعمل على الاستضافة المشتركة (cPanel وما يشبهها).

## الأدوار
- **مسؤول التدريب التعاوني:** كل الصلاحيات، واستيراد كشوف Excel، وحسابات المتدربين، والخريجون، والسجل، والإعدادات.
- **مشرف الكلية:** متدربوه، وتسجيل الزيارات، ومراجعة التقارير الأسبوعية، وإرسال رابط تقييم الجهة.
- **المتدرب:** بياناته وزياراته والإعلانات، وكتابة التقرير الأسبوعي.
- **المشرف الميداني:** يعبّئ نموذج التقييم برابط خاص دون حساب.

## النسخة التجريبية
المجلد `docs/` فيه نسخة تجريبية تعمل في المتصفح ببيانات وهمية (تُنشر عبر GitHub Pages).

## التثبيت
ارفع الملفات إلى الاستضافة، ثم افتح `install.php` وأكمل البيانات، ثم احذف `install.php`.
التفاصيل الكاملة في [دليل التشغيل](اقرأني-دليل-التشغيل.md).

> ملاحظة: مجلد `docs/` خاص بالنسخة التجريبية ولا يلزم رفعه إلى الاستضافة.
